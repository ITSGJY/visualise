# Visual design guide

Borrow upstream's flat, semantic, legible visual language.

- One primary visual, optional secondary visual that teaches a distinct relationship.
- Use meaningful colors: neutral structural nodes, one emphasis family, status-specific warning/error colors.
- Label quantities with units, legends when needed, and directions with arrowheads.
- Keep shapes and text inside viewBox. SVG should have adequate padding.
- Align related nodes; route arrows around, not through, boxes; avoid crossing connectors.
- Prefer concise titles and unobstructed subtitles; avoid text smaller than 11px.
- Support light/dark themes and sufficient contrast; do not rely on hue alone.
- No decorative rainbow gradients, unnecessary drop shadows, or emoji-based icons.
- On mobile, stack comparisons instead of squeezing labels into illegibility.
- Use accessibility labels, keyboard focus, descriptive alt text as supported.
